SX10 Niche Airflow - 3D viewer
Upload this whole folder (index.html + web_data/) to a web server and open index.html.
Needs internet access for the 3D library (three.js from cdnjs) and fonts.
It does not work by double-clicking index.html (browsers block loading the data files from disk);
for offline use, open niche-airflow_open-me.html instead.
Tip: enable gzip/brotli compression for .bin files on the server to speed up loading.
